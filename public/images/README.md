# Images Directory Structure

このディレクトリ構造に従ってローカルイメージを保管してください。

## セクション別イメージディレクトリ

### `/hero`
Hero背景イメージ用
- `bg.jpg` - Hero背景画像（推奨: 1920x1200px以上）

### `/founder`
Founder セクション用
- `portrait.jpg` - Founder肖像画（推奨: 400x400px）

### `/content-blocks`
Content Blocksセクション用
- `block-1.jpg` - 最初のコンテンツブロックイメージ
- `block-2.jpg` - 2番目のコンテンツブロックイメージ
- など...

### `/gallery`
ギャラリースライダー用
- `item-1.jpg` - ギャラリーアイテム1
- `item-2.jpg` - ギャラリーアイテム2
- `item-3.jpg` - ギャラリーアイテム3
- `item-4.jpg` - ギャラリーアイテム4
- など...

## ファイル形式
- JPG / PNG / WebP
- 推奨形式: WebP（軽量で高品質）

## 使用方法
ファイルを保管後、admin CMS エディターでパスを `/images/セクション名/filename.ext` の形式で指定してください。

例:
- `/images/hero/bg.jpg`
- `/images/founder/portrait.jpg`
- `/images/gallery/item-1.jpg`
